## Как делать один шаг (рецепт)
1. Найди раздел, перечисли внешние имена, которые он использует (`grep`, или временно запусти через `"use strict"` — необъявленное упадёт).
2. Создай модуль `src/…/x.js` с функцией `init(ctx)`; в `ctx` передай только нужные функции/данные (`wallet`, `fbAuth`, `toastAny`, `show`…), не весь мир.
3. Перенеси код, **ничего не переписывая**. Экспорты — только то, что вызывают снаружи.
4. Подключи в `src/main.js` (в `PG`), вызови `init` из `game.html` в том же месте, где раздел исполнялся раньше (порядок инициализации важен).
5. `npm run build`, `node --test tests/*.test.cjs` — всё зелёное; открой игру и проверь руками затронутый экран.
6. Один PR на шаг, в `release-notes.md` ничего не пиши (для игроков изменений нет), строку в `HANDOFF.md`.

## Правила безопасности
- Не менять формат сообщений комнаты, ключи `localStorage`, структуру `wallet` и `/profiles` во время выноса.
- Не переименовывать id элементов и обработчики, на которые опираются тесты (`#helpBtn`, `#prefs`, `#tip`, `#ok`…).
- Тесты вынесенных модулей писать **до** выноса (характеризующие), а не после.
- Если шаг растёт больше 600 строк диффа — раздели.
