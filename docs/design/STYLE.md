# Puzzlegrad — единый стиль «Пазл-мозаика»

Главный мотив игры — **пазл**: всё, что связано между собой, склеено выступом и пазом, как кусочки мозаики.

## Мотив
- **Кусочек пазла** — форма для всех «плиток» интерфейса: нижняя панель, режимы на главной, шапка настройки партии. Скругление 16–20 px, круглый выступ (`tab`) входит в паз (`notch`) соседа с зазором 2 px.
- Реализация: `jigsawFrame()` в `web/game.html` рисует контур SVG под прозрачными кнопками. Элемент получает `data-jp`, цвет `data-jc` (`gold` или hex) и рёбра `data-je="r:tab,b:notch"`.
- Блик сверху (белый градиент 26 % → 0) и тёмная обводка 1.4 px у каждого кусочка.

## Цвет — у каждого раздела свой
| Что | Цвет |
|---|---|
| Играть онлайн, открытый раздел | золото `#f2b84b` |
| С друзьями | синий `#4c8dff` |
| С ботами | зелёный `#3fc27a` |
| Локально | фиолетовый `#b06cf0` |
| Главная | индиго `#6a7dff` |
| Профиль | бирюзовый `#22b8cf` |
| Магазин | оранжевый `#f2994a` |

Цвет кусочка = смесь цвета раздела с тёмно-синим фоном (50 %…72 %), подписи светлые `#eef2ff`, на золоте — тёмно-коричневые.

## Шрифты и формы
- Заголовки — Unbounded (`--f-display`), текст — Onest (`--f-body`).
- Карточки: градиент белого 7.5 % → 2.5 %, светлая кромка сверху, тень вниз.
- Подзаголовки разделов — с золотой чёрточкой (`.h3`).
- Шапка раздела закреплена наверху и совпадает по цвету с фоном экрана.

## Правило
Новый экран использует эти же кусочки, цвета и подзаголовки; свой «особый» вид без причины не делаем.
