# Публикация в Google Play

Всё для страницы в магазине лежит в репозитории, файл приложения собирается автоматически.

## Что загружать

| Что | Где взять |
| --- | --- |
| Файл приложения (AAB) | GitHub → Releases → последний релиз → `MosaicKingdom-1.0.N-google-play.aab` |
| Значок 512×512 | `store/icon-512.png` |
| Баннер 1024×500 | `store/feature-1024x500.png` |
| Скриншоты телефона 1080×1920 | `store/screenshots/` |
| Политика конфиденциальности | https://github.com/crownfall90-dot/play/blob/main/docs/privacy-policy.md |

Скриншоты и графика пересобираются командой `node scripts/store-assets.js` после `./scripts/wrap-web.sh`.

## Шаги в Play Console

1. Заведите аккаунт разработчика: https://play.google.com/console (разовый взнос 25 $).
2. **Создать приложение** → название «Мозаика Королевства», язык русский, «Игра», «Бесплатное».
3. **Тестирование → Закрытое тестирование** → создайте выпуск, загрузите `.aab`, вставьте текст из `release-notes.md`.
   У новых личных аккаунтов Google требует закрытый тест: минимум 12 тестировщиков в течение 14 дней. Только после этого откроется доступ к рабочей версии.
4. При первой загрузке согласитесь на **подписание приложений в Google Play**. Ключ `app/release.keystore` из репозитория станет ключом загрузки.
5. Заполните **Контент приложения** (ответы ниже) и **Основную страницу** (тексты ниже).
6. После теста: **Рабочая версия → Создать выпуск** → тот же `.aab` → отправить на проверку.

Каждая следующая версия: слить изменения в `main` → GitHub соберёт новый `.aab` → загрузить его в новый выпуск. Игроки получат окно «Доступно обновление» от Google Play, а после обновления игра покажет «Что нового».

## Тексты страницы

**Название (до 30 символов):** Мозаика Королевства

**Краткое описание (до 80 символов):**
Стройте города, дороги и крепости из общей стопки карт с друзьями онлайн

**Полное описание:**

Мозаика Королевства — настольная игра о строительстве королевства для 2–5 игроков.

Игроки по очереди тянут карту из общей стопки и пристраивают её к полю: продолжают дороги, расширяют города, огибают реки и окружают крепости. Ставьте свою фигурку на город, дорогу или крепость — объект станет вашим, и когда его достроят, очки получите вы. Даже если последнюю карту положил соперник.

Когда стопка закончится, побеждает тот, у кого больше очков.

• Поле в 3D: двигайте его пальцем, приближайте щипком, меняйте угол обзора
• Онлайн с друзьями: создайте комнату и отправьте код, каждый играет со своего телефона
• За одним телефоном: передавайте телефон по кругу
• Боты-соперники для тренировки, в том числе без интернета
• Свои правила: размер стопки, реки, число фигурок, время на ход
• Подсчёт очков: дорога — 1 за карту, город — 2 за карту, крепость — 9

Без рекламы и покупок.

**Категория:** Игры → Настольные игры. **Теги:** настольная игра, стратегия, мультиплеер.

## Ответы для «Контента приложения»

- **Политика конфиденциальности:** ссылка из таблицы выше.
- **Реклама:** нет.
- **Доступ к приложению:** все функции доступны без входа.
- **Возрастной рейтинг (анкета IARC):** категория «Игры». Насилия, страха, азартных игр, нецензурной лексики, наркотиков нет. Общение между игроками — нет (в комнате видны только имена). Покупок нет. Ожидаемый результат: 3+ / PEGI 3.
- **Целевая аудитория:** 13 лет и старше. Если выбрать младше 13, приложение попадёт под требования программы «Для всей семьи» и проверка станет строже.
- **Безопасность данных:**
  - Собирает ли приложение данные: **да** (только в онлайн-режиме).
  - Личная информация → **Имя** (никнейм, который игрок вводит сам): собирается, не передаётся третьим лицам для их целей, цель — «Функции приложения», необязательно.
  - Активность в приложении → **Другой пользовательский контент** (ходы партии): цель — «Функции приложения».
  - Данные шифруются при передаче: **да**. Удаление по запросу: данные удаляются автоматически через 12 часов.
- **Новостное приложение / COVID / госуслуги:** нет.

## Подпись и ключ

Сборки подписываются ключом `app/release.keystore` (пароль задаётся секретами `KEYSTORE_PASSWORD` и `KEY_PASSWORD`, иначе используется пароль по умолчанию из `app/build.gradle`). Для Google Play это только ключ загрузки: при подписании через Google Play его можно заменить через поддержку, если он утечёт.
