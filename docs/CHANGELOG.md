# Журнал версий

Каждая версия: что увидят игроки (текст из `release-notes.md` в момент выпуска) и что изменилось в коде (заголовки слияний в main). Создаётся `scripts/changelog.py` из тегов релизов; при каждом выпуске обновляется автоматически. Служебные детали панели владельца и сборки есть только здесь.

Версии 181–183 вышли с общей формулировкой «Небольшие исправления и улучшения»: заметки к ним не были заполнены вовремя. 183 вышла автоматически при слиянии PR 83, до того как выпуск стал выполняться только по команде.
