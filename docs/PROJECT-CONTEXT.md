## Подтверждённый релиз

`1.0.210` (`v210`) опубликован из `ed061a44898c66daa9cf44045c71650bfda2c568`. Владелец подтвердил получение push-уведомления и обновления. Публикация включала регрессионные проверки, сборку APK, сверку SHA-256 версии 1.0.209, проверку совпадения сертификата подписи и обновление `latest.json`.

## Текущий этап 2

Добавлены диагностика FCM и локальный аккаунтный слой: Google-вход через Credential Manager, сохранение профиля и постоянного цвета из ограниченной палитры. Выход очищает идентификатор и имя, но сохраняет выбранный цвет. Серверная проверка Google ID token, синхронизация профиля между устройствами и серверная роль владельца пока не реализованы.

Далее: отдельный тестовый Firebase, серверная проверка токена, синхронизация устройств, защита данных и реальные проверки двух аккаунтов Android/web. Риск раскрытия основного signing material остаётся нерешённым; ключ не меняется без плана совместимости.
