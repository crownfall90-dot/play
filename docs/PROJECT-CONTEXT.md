## Текущий этап 2

Добавлены диагностика FCM, локальный аккаунтный слой и его подключение к UI: Google-вход через Credential Manager, выбор постоянного цвета из шести значений и отображение профиля. При отсутствии Google client id интерфейс показывает явное состояние, а не пытается выполнить вход.

Серверная проверка Google ID token, синхронизация профиля между устройствами и серверная роль владельца пока не реализованы. Далее: отдельный тестовый Firebase, серверная проверка токена, синхронизация устройств, защита данных и реальные проверки двух аккаунтов Android/web. Риск раскрытия основного signing material остаётся нерешённым; ключ не меняется без плана совместимости.
