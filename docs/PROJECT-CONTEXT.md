# Puzzlegrad: постоянный контекст разработки

Репозиторий: `crownfall90-dot/play`. Рабочая ветка этапа 2: `dev/stage2-account-network-20261029`.

## Подтверждённый релиз

`1.0.210` (`v210`) опубликован из `ed061a44898c66daa9cf44045c71650bfda2c568`. Владелец подтвердил получение push-уведомления и обновления. Публикация включала регрессионные проверки, сборку APK, сверку SHA-256 версии 1.0.209, проверку совпадения сертификата подписи и обновление `latest.json`.

## Архитектура и данные

Основное игровое ядро и UI находятся в `web/game.html`; Android — тонкая WebView-обвязка и asset, создаваемый `scripts/wrap-web.sh`. Сетевые комнаты, presence и аккаунтный слой используют Firebase при наличии конфигурации. Offline-сохранение партии хранится локально.

## Текущий этап 2

Текущий пакет добавляет диагностику подписки FCM: Firebase принимает запрос, результат сохраняется локально, отдельно проверяется наличие токена. Это не доказывает показ уведомления на устройстве.

Далее запланированы: Google-вход, постоянный цвет игрока, серверная роль владельца, отдельный тестовый Firebase, синхронизация устройств и защита данных. Отдельный тестовый Firebase пока не подтверждён. Риск раскрытия основного signing material остаётся нерешённым; ключ не меняется без плана совместимости.
